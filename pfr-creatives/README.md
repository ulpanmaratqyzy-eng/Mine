Мәтіндерді `scripts.py` файлынан өзгертуге болады (`*жұлдызша*` = түспен ерекшеленетін сөз).

## Қайта жасау
```
pip install piper-tts numpy pillow
# дауыс: huggingface.co/rhasspy/piper-voices → kk/kk_KZ/issai/high
# шрифт: Montserrat (Google Fonts, OFL)
python3 make_creatives.py --voice kk_KZ-issai-high.onnx --font Montserrat.ttf --out videos
```
Дауыс — ISSAI KazakhTTS (Piper) синтезі, ал музыканы скрипт өзі генерациялайды, сондықтан авторлық құқық мәселесі жоқ.

## Өз видеоларыңыздан креатив жасау (беттер жабылады)

`footage.py` екі қадаммен жұмыс істейді:

1. **Беттерді жабу.** Әр кадрда беттер автоматты табылады (OpenCV YuNet) және мозаика мен блюрмен жабылады. Бет қолмен жабылғанда немесе бұрылғанда да 3 секундқа дейін жабық тұрады. Клип 9:16-ға кесіледі, адам кадр ортасында қалады. Әр клипке `*_check.jpg` тексеру парағы шығады.
   ```
   python3 footage.py anon --model face_detection_yunet_2023mar.onnx --out anon клип1.mp4 клип2.mov
   ```
2. **Креатив құрастыру.** `scripts.py` сценарийлері алынып, жабылған клиптер фонға қойылады. Ауырсыну бөлігінде суық түс, шешім бөлігінде жылы түс беріледі. Мәтін, дауыс және музыка бұрынғыдай қосылады.
   ```
   python3 footage.py compose --voice kk_KZ-issai-high.onnx --font Montserrat.ttf --out videos_own --ids 01_negizgi,02_trevoga anon/*.mp4
   ```
Жарияламас бұрын әр `*_check.jpg` парағын қарап шығыңыз. Видеодағы адамдардан жарнамаға келісім алынғанына көз жеткізіңіз.
