Мәтіндерді `scripts.py` файлынан өзгертуге болады (`*жұлдызша*` = түспен ерекшеленетін сөз).

## Қайта жасау
```
pip install piper-tts numpy pillow
# дауыс: huggingface.co/rhasspy/piper-voices → kk/kk_KZ/issai/high
# шрифт: Montserrat (Google Fonts, OFL)
python3 make_creatives.py --voice kk_KZ-issai-high.onnx --font Montserrat.ttf --out videos
```
Дауыс — ISSAI KazakhTTS (Piper) синтезі, ал музыканы скрипт өзі генерациялайды, сондықтан авторлық құқық мәселесі жоқ.
